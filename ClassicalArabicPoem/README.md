# Classical Arabic Poems Java Project

Welcome to the **Classical Arabic Poems Java Project**! This project follows a layered architecture and is designed to be a smooth, standalone application.

## Overview

This Java project encapsulates classical Arabic poems using a well-structured layered architecture. The project has been exported as a **Runnable JAR file** for seamless execution.

## Getting Started

### Prerequisites

Before running this application, ensure the following are in place:

1. **XAMPP Control Panel:** If not already installed, download and install it.
2. **JDK:** Ensure you have Java Development Kit installed.

### Running the Application

To run the application:

1. Launch **XAMPP** and start the **Apache & MySQL** services. Verify their status with the green indicator icons. If not, reinstall XAMPP and retry.

2. Access the **MySQL Admin** panel by clicking the "Admin" button in the MySQL section.

3. Import the provided `setup.sql` file located in the `db/` directory of the project within **MySQL Admin**.

4. Exit the MySQL Admin.

5. Double-click on the `your-app.jar` file or execute it via command line to start your **Classical Arabic Poems** project.

## Additional Notes

- **Dependencies:** The `lib/` directory contains necessary external JAR files required for smooth operation.
- **Configuration:** Customize application settings in the `config/` directory, including `application.properties` (template) and `log4j2.properties`.
- **Logging:** All application log files are stored in the `logs/` directory.
- **Installer:** If provided, use `installer.sh` (or `installer.bat` for Windows) for additional setup or configuration steps.
